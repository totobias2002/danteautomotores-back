<objective>
La API del perfil propio: ver (`GET /api/usuarios/me`) y completar o editar (`PUT /api/usuarios/me`). Es el camino con el que una cuenta de Google o una cuenta vieja completa apellido, teléfono y DNI (D-07, D-08, D-09) y la base del perfil editable (AUTH-05).

Objetivo de la fase (ROADMAP, textual; no está en formato de user story): "Toda persona que quiera comprar o cotizar tiene una cuenta con identidad completa (nombre, mail, teléfono, DNI), ya sea que entre con mail o con Google".

Purpose: cierra el camino del tracer (03-01): ahora una cuenta incompleta puede dejar de serlo de punta a punta, verificado por el humo contra un back real. Las pantallas del front (03-11, 03-13) consumen estos dos endpoints. El cambio de contraseña y el reenvío del mail de confirmación suman endpoints al mismo controlador en 03-10.

Output: DTOs, mapper, `UsuarioService`, `UsuarioController` y sus tests; el humo ampliado con el flujo de completar datos.
</objective>
