| Boundary | Description |
|----------|-------------|
| navegador a API (consulta, perfil, contraseña) | Entradas del usuario autenticado |
| link con token a otros orígenes | El Referer podría llevar el query de /confirmar-email o /restablecer-contrasena |
| front a autoridad del back | Los botones protegidos son una cortesía de UX |
