<objective>
Mostrar en cada fila del listado de autos del panel admin (`../danteautomotores-front/src/pages/admin/AdminDashboardPage.jsx`) una miniatura de la foto de portada (la de orden 0 de `publicacion.fotos`), o un placeholder con icono de auto si no tiene fotos, para que el admin reconozca cada auto de un vistazo. Las miniaturas de Cloudinary se piden ya recortadas a 160x120 (`c_fill,w_160,h_120,q_auto,f_auto`) para no bajar la foto completa en cada fila.

Purpose: hoy el listado es solo texto (marca, modelo, anio, precio); con varios autos parecidos el admin tiene que leer cada fila. La miniatura de portada es el patron familiar (Kavak / Mercado Libre) que pide el proyecto.
Output: `../danteautomotores-front/src/utils/cloudinary.js` (nuevo) y la fila del listado del panel con miniatura responsive, lazy y con alt descriptivo.

Solo front: el backend ya devuelve `fotos: [{ id, url, orden }]` ordenadas por `orden` en GET /api/admin/publicaciones (`src/main/java/com/danteautomotores/mapper/PublicacionMapper.java`, lineas 34-37) y tambien en las respuestas de PATCH estado/destacado que usa `actualizarEnLista`. No se toca el backend.

El front es un repo git aparte: los commits de codigo van en `../danteautomotores-front` (por ejemplo `git -C ../danteautomotores-front commit ...`); el PLAN/SUMMARY de esta tarea se commitea en el repo back.
</objective>
